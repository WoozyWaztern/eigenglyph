# Eigenyth

Мультиплеерный 3D‑шутер от первого лица, где **всё** нарисовано символами: мир, игроки‑шарики, руки, дробовик, нож, газировка, меню, чат, кнопки и даже курсор.

*Eigen* — «собственный вектор» из линейной алгебры (на ней держится вся 3D‑математика), *Glyph* — символ. ΣVOID осталось подзаголовком.

---

## Самый быстрый запуск — Eigenyth.exe

1. Дважды кликни по **Eigenyth.exe**. Откроется чёрное окно сервера, и сама запустится игра в браузере.
2. Не закрывай это окно, пока играешь: закрыл окно — сервер остановился.
3. Если Windows покажет «Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без цифровой подписи.
4. Если брандмауэр спросит про доступ к сети, разреши, иначе друг не подключится.

Аккаунты сохраняются в папке `eigenglyph-data` рядом с exe.

## Запуск из исходников (Visual Studio Code)

1. Установи **Node.js** (LTS): https://nodejs.org
2. Открой папку `eigenglyph` в VS Code (File → Open Folder).
3. Открой терминал (Ctrl + `) и введи:
   ```
   npm start
   ```
   Или просто нажми **F5**: конфигурация «▶ EIGENGLYPH server» уже настроена.
4. Открой в браузере: **http://localhost:3000**

Ставить ничего не нужно: у проекта нет зависимостей, WebSocket‑сервер написан с нуля (`miniws.js`).

## Игра с другом

- **Одна Wi‑Fi сеть:** при запуске сервер пишет в терминал строку `friend: http://192.168.x.x:3000`. Друг открывает этот адрес у себя. Если не подключается, разреши Node.js в брандмауэре Windows.
- **Через интернет:** используй туннель, например `playit.gg`, `ngrok http 3000` или Radmin VPN / ZeroTier, и дай другу полученный адрес.

## Что есть

- Регистрация: никнейм и пароль. Новый ник = новый аккаунт, пароль хранится в виде хеша (`data/accounts.json`).
- Главное меню: большое название из символов и кнопка PLAY, на фоне вращается ASCII‑куб.
- 3D‑мир: на каждый символ экрана пускается луч (voxel DDA), яркость превращается в символ из шкалы `.,-~:;=!*#$@`.
- Игроки — шарики со светящимися глазами и руками, которые сливаются с телом.
- Дробовик: **27** урона, 6 патронов, помповая анимация, отдача, вспышка, прицеливание.
- Нож: **7** урона, взмахи поочерёдно в обе стороны.
- Газировка: +25 HP, анимация «открыть и выпить», перезарядка 7 секунд.
- Раны остаются там, куда попала пуля, и из них стекает кровь. Кровь капает и на пол.
- Раненый игрок замедляется: чем меньше HP, тем медленнее, плюс короткое оглушение после попадания.
- Смерть: камера падает набок, через 3.5 секунды возрождение.
- Чат в стиле старого Roblox: полоса внизу на всю ширину и пузыри над головой. Над игроком максимум 3 пузыря, каждый исчезает через 6 секунд.
- Сверху показаны твоё HP и HP того, в кого ты попал. Справа сверху — лента убийств.
- Звук генерируется кодом, без аудиофайлов.

## Отдельное окно

Eigenyth.exe открывает игру с сервера https://eigenglyph.onrender.com в своём окне без вкладок и адресной строки (через Microsoft Edge, он есть в каждой Windows 10/11).
Новые режимы, зомби и сохранение аккаунтов работают на Node-сервере (`server.js`): чтобы играть у себя на ПК по Wi-Fi — `npm start`.
Чёрной консоли больше нет. Закрыл окно игры → сервер на твоём ПК остановился.

## Играть с кем угодно через интернет — без exe и без предупреждений

Лучший способ: выложить игру на бесплатный сервер. Тогда друг просто открывает ссылку и нажимает
**INSTALL AS APP** на экране входа (или значок «Установить» в адресной строке Edge/Chrome):
у него появляется приложение EIGENGLYPH с иконкой на рабочем столе и в меню Пуск, оно открывается
в отдельном окне, и **никаких синих окон Windows не будет** — ведь exe никто не скачивает.

Как выложить (без программ, только браузер, ~10 минут):
1. Зарегистрируйся на github.com → **New repository** → назови `eigenglyph` → Create.
2. Нажми **uploading an existing file** и перетащи туда всё содержимое папки `eigenglyph` → Commit.
3. Зарегистрируйся на render.com (можно войти через GitHub) → **New → Blueprint** → выбери репозиторий `eigenglyph` → Apply.
   Файл `render.yaml` уже лежит в папке, Render всё настроит сам.
4. Через пару минут получишь ссылку `https://eigenglyph-xxxx.onrender.com` — это и есть игра. Кидай её друзьям.

На бесплатном тарифе сервер засыпает, если в него никто не играет (первый вход тогда ждёт около минуты),
и аккаунты сбрасываются при перезапуске сервера.

Чтобы Eigenyth.exe тоже заходил на этот сервер, положи рядом с ним файл `eigenglyph.json`:
```json
{ "server": "https://eigenglyph-xxxx.onrender.com" }
```

## Синее окно Windows (SmartScreen)

Windows показывает его для **любой** скачанной программы без цифровой подписи — это защита самой Windows,
программа сама её отключить не может. Варианты:
- нажать **Run** («Подробнее → Выполнить в любом случае»);
- купить сертификат подписи кода (платный, на год) и подписать exe;
- **играть через ссылку / «INSTALL AS APP»** (см. выше) — бесплатно и без предупреждений.

## Обновление 1.3

### Сохранение аккаунтов (больше ничего не сбрасывается)
Бесплатный render.com стирает все файлы, когда сервер засыпает (15 минут без игроков). Поэтому аккаунты теперь
хранятся в бесплатной базе **Upstash Redis**. Один раз настроить (~5 минут):
1. Зайди на **upstash.com** → Sign up (можно через GitHub) → **Create Database** (Redis) → любое имя, регион поближе (например Frankfurt), план **Free**.
2. На странице базы найди блок **REST API** и скопируй два значения: `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
3. render.com → твой сервис **eigenglyph** → **Environment** → **Add Environment Variable** → добавь обе переменные с этими значениями → **Save Changes**. Сервер перезапустится.
4. Проверка: в render → **Logs** должна быть строка `accounts: N (Upstash Redis database)`.

Без этих переменных игра работает как раньше (файл `data/accounts.json`) — удобно для игры на своём ПК.

| команда | что делает |
|---|---|

### Баг «вышел и зашёл под другим ником, а показывает старый»
Причина: на медленном сервере ответ на старый вход приходил позже и «перезаписывал» новый. Теперь каждый вход
имеет свой номер, старые ответы игнорируются; выход происходит мгновенно без разрыва соединения. Если тот же аккаунт
«висит» в другой вкладке, вход с правильным паролем просто выбивает старую сессию.

### Медленный сервер
Бесплатный render.com засыпает после 15 минут без игроков (первый вход потом ~30–60 с) и даёт мало процессора.
Это ограничение бесплатного тарифа; платный тариф Starter убирает засыпание.

## Обновление 1.7

### Пати (приглашения) — играть вместе
- В лобби под персонажем 4 слота. Нажми **+ invite** → список друзей онлайн (кнопка INVITE) или впиши любой ник онлайн-игрока.
- Приглашённому сверху появляется полоса **«★ ник invites you to the party · ACCEPT / DECLINE»**.
- Лидер (★) выбирает режим и жмёт PLAY — **все участники из лобби сразу попадают в тот же матч**.
  В CAPTURE Σ пати играет в одной команде. Участник может нажать **JOIN**, если лидер уже в матче.
- Лидер может выгнать участника (наведи на слот → kick), любой может выйти кнопкой **leave**.

### ZOMBIES — соло или вместе
- Один — как раньше. С пати — один общий забег: зомби идут к ближайшему живому игроку, в волне больше зомби.
- Упавший игрок возвращается, когда волна зачищена; игра заканчивается, только когда упали все.
- Звёзды за волну получает каждый.

### Прочее
- **Молотов**: бутылки бесконечные, но бросок раз в **10 секунд** (в слоте видно отсчёт / READY).
- Пистолеты: рукоять короче, кулаки обхватывают её целиком — магазин больше не торчит вниз.
- Убраны «перчатки»: руки снова одного цвета с рукавами.
- F9: `kill <ник>` — убить игрока в матче.
